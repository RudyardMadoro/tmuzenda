# Design System

The interface uses a warm neutral palette, serif display typography, compact uppercase eyebrow labels, restrained borders, and generous responsive spacing.

Shared classes such as `container-custom`, `btn-primary`, `btn-secondary`, `btn-light`, `eyebrow`, and `filter-chip` are defined in `src/app/globals.css`. Reusable presentation components live in `src/components/ui/`.

Preserve accessible contrast, visible focus states, 44-pixel minimum interactive targets, existing transition timing, and the established mobile/tablet/desktop breakpoints when extending the interface.
