# Accessibility

TK Muzenda Properties uses semantic landmarks, a skip link, labelled navigation, keyboard-operable menus and dialogs, visible focus styles, descriptive image alternatives, and reduced-motion safeguards.

Interactive catalogue controls use native buttons, inputs, fieldsets, labels, live result counts, validation messages, and `aria-disabled` where appropriate. `AccessibleGallery` and product dialogs manage keyboard focus and expose meaningful labels.

Run automated checks alongside keyboard-only and screen-reader smoke tests before release. Verify text contrast, focus order, mobile-menu escape behavior, dialog focus return, form errors, and content at 200% zoom.
