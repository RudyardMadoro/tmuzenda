# Contributing to TK Muzenda Properties

Contributions should preserve the existing brand, accessibility, responsive behavior, and typed content model.

## Setup

```bash
git clone https://github.com/RudyardMadoro/tmuzenda.git
cd tmuzenda
npm ci
copy .env.example .env.local
npm run dev
```

## Before submitting changes

Run `npm run check`. Keep changes focused, add or update tests when behavior changes, and do not commit secrets, generated build output, unverified business details, or imagery without confirmed usage rights.

Report conduct, security, or project-maintenance concerns to `rudyardmadoro@gmail.com`.
