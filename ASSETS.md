# Asset Register

TK Muzenda Properties uses a combination of supplied project imagery and illustrative photography inherited from the original template.

## Current application assets

- `public/images/projects/`: supplied project-study imagery, optimized as WebP.
- `public/images/services/cabinetry/`: supplied cabinetry imagery, optimized as WebP.
- `public/images/hero/`, `properties/`, `services/`, and `about/`: licensed illustrative photography used while verified company photography is prepared.
- `src/app/favicon.ico`: current browser icon; a verified TK Muzenda Properties brand-icon file has not yet been supplied.

Illustrative imagery must not be described as completed client work or live accommodation inventory. Replace it only with authorized assets and preserve meaningful alt text.

## Retained source attribution

The repository originated from the Horizon Estate template. Its MIT copyright and template-media notice remain in [LICENSE](LICENSE) because required legal attribution must not be removed. Original illustrative photography remains subject to its source terms, including the [Unsplash License](https://unsplash.com/license) where applicable. Newly supplied images remain subject to the owner's applicable rights.

Unused template showcase screenshots, agent portraits, journal covers, default framework SVGs, and the unrelated Takura Muzenda logo were removed after confirming that the application did not reference them.
